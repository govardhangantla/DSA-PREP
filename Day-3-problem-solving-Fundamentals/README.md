# Java Number Problems 🔢

This repository contains basic **Java programs for solving number-based problems** as part of my DSA learning journey.

The programs focus on building strong fundamentals in:
- Loops
- Conditions
- Mathematical logic
- Digit manipulation
- Factors
- Prime numbers
- GCD & LCM
- Number patterns

## 📂 Programs

| Program | Description |
|---|---|
| `Armstrongnumber.java` | Checks whether a number is an Armstrong number |
| `factorsofnumber.java` | Finds all factors of a number |
| `FibonacciSeries.java` | Prints the Fibonacci series |
| `GCD.java` | Finds the Greatest Common Divisor of two numbers |
| `LCM.java` | Finds the Least Common Multiple of two numbers |
| `numberpattern.java` | Prints basic number patterns |
| `PERFECTNUMBER.java` | Checks whether a number is a perfect number |
| `PowerofNumber.java` | Calculates the power of a number |
| `PrimeNumber.java` | Checks whether a number is prime |
| `StrongNumber.java` | Checks whether a number is a strong number |
